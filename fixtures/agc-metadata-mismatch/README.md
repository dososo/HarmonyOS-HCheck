# F008：AGC 元数据不一致

## 目的

本地版本、应用名称摘要或隐私摘要与脱敏 AGC 快照不一致。

## 故障植入

只在模拟响应中改变一个字段。

## 当前状态

`specification`。尚未声称为可编译 HarmonyOS 工程。

## 预期

HOS-META-001

## 建设步骤

1. 在具备合法 HarmonyOS SDK 的环境中使用官方 Stage 模板创建最小工程；
2. 固定 SDK、工具和模板版本；
3. 只植入本规格描述的主故障；
4. 运行 Release 构建（如要求）；
5. 执行 HCheck 扫描和必要运行时流程；
6. 保存脱敏黄金结果；
7. 建立修复对照；
8. 更新 `fixture.yml` 状态为 `compilable`。

## 安全

不使用真实生产服务、真实用户、真实 AGC 凭证或可用于生产签名的材料。

## 备注

当前规则样例未包含 HOS-META-001，先完成契约。
