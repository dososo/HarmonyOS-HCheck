# 安全、隐私与凭据

## 不得提交

- 密码、Token、API Client Secret、私钥、证书、签名材料与 `.env`；
- 真实 HAP/APP、真实用户数据、设备序列号、原始 Hilog、截图、录屏、网络请求或响应；
- 绝对个人路径、账号标识、生产项目标识、不可撤销权益或受限文档；
- 与 HCheck 无直接关系的工作资产、提示词、交接记录或第三方项目内容。

## 安全默认值

- `.hcheck/`、`.env*`、证书扩展名和构建产物被 `.gitignore` 排除；
- 配置只引用环境变量名，例如 `HCHECK_AGC_CLIENT_SECRET`，绝不写入变量值；
- 报告输出必须经过路径与敏感字段脱敏；
- 解析与进程适配器设置输入大小、超时和执行边界；
- 任何真实外部操作必须单独授权，且不应由公开 CI 自动触发。

## 公开前自查

```bash
git grep -n -I -E 'BEGIN [A-Z ]*PRIVATE KEY|Authorization:.*Bearer|client_secret.*[:=]|access_token.*[:=]' || true
git status --short
```

这只是辅助检查，不替代人工审查。发现可能泄露时，请先停止发布，按 [安全政策](../SECURITY.md) 建立私密处置路径。
