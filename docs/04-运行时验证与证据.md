# 运行时验证与证据

## 证据原则

- 证据必须说明来源、时间、哈希、脱敏状态与完整性；
- 缺失、损坏、超时或无法复核的证据只能得到 `INCOMPLETE`/失败，不能得到 PASS；
- 同一流程应能通过录制输入重放，而无需读取真实设备；
- 日志、截图、包文件与服务响应默认视为敏感材料，公开前必须逐项审查。

## 设备与外部操作

默认 CLI 不会任意执行 HDC、安装、启动、停止、卸载、Hilog、网络登录或 AGC 写操作。涉及真实设备、真实账号、真实 HAP 或外部服务的操作必须具备：

1. 目标、软件包哈希和允许动作的明确授权；
2. 最小权限与非生产范围；
3. 可撤销的执行路径和脱敏证据；
4. 结束后的清理与终态核验。

可使用 [运行时流程模板](../templates/runtime-flow-template.yml) 描述可审计的录制或测试流程。公开仓库只接受脱敏、可合法分享的录制样例。
