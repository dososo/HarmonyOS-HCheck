# 官方工具与 AGC 集成

HCheck 通过独立适配器对接外部能力，核心规则不依赖其安装路径或登录态。集成能力以当前代码、测试和官方文档为准；未实现或不可用的能力必须返回明确状态。

| 集成 | 公开边界 |
|---|---|
| Hvigor | 通过项目 wrapper 进行受控构建能力探测与编排，不伪造构建成功 |
| HDC | 通过可注入设备端口读取/验证；真实写操作不属于默认 CLI 行为 |
| AppAnalyzer / DevEco Testing | 仅导入公开、脱敏的正式报告或录制输入，不读取内部数据库 |
| AppGallery Connect | 仅建模显式、只读的公开 API 集成边界；不抓取登录态网页，不自动提交审核 |

使用任何外部能力前，请重新核验对应官方文档、工具版本、账号权限与数据处理要求。不要把网页自动化、私有接口或个人登录凭据作为公共集成方案。
