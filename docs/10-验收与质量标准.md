# 发布范围与检查

## 发布前必须通过

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm security:deps
pnpm package:cli
git diff --check
```

同时人工确认：

- `git status --short` 没有 `.env`、`.hcheck/`、证书、真实软件包、日志或其他本地证据；
- `LICENSE`、`NOTICE`、README、贡献与安全文件准确且彼此一致；
- 公开差异不包含个人路径、账号标识、真实 Token、设备标识、生产信息或非项目资产；
- SBOM 与依赖漏洞检查结果已由发布者审阅；
- GitHub 已配置 About、Topics、分支保护、私密漏洞报告和维护者权限。

## 当前发布范围

本项目发布的是可复现的 TypeScript 源码、规则、Schema、公开测试 Fixture、示例、文档和本地 CLI 构建流程。仓库不发布 npm 包、不发布生产签名材料、不托管云服务，也不附带任何真实外部环境证据。

## 不作出的承诺

- 不保证审核、上架、兼容性、隐私合规或安全审计结果；
- 不以公开测试或单一环境结果外推到所有设备、SDK、地区或应用；
- 不声明真实用户账号、商店提交流程或生产服务已被本仓库覆盖；
- 不将证据不完整、工具不可用或网络错误解释为通过。
