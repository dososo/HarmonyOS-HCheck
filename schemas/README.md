# Schema 目录

- `hcheck-config.schema.json`：项目配置。
- `rule.schema.json`：规则定义。
- `rule-pack-signature.schema.json`：规则包签名清单。
- `evidence.schema.json`：证据对象。
- `finding.schema.json`：单条问题。
- `report.schema.json`：扫描报告。
- `runtime-flow.schema.json`：运行时流程。
- `account-deletion-stub.schema.json`：账号注销本地测试桩合同。
- `fixture.schema.json`：样例工程规格。

所有 Schema 使用 JSON Schema 2020-12。破坏性变更必须通过 ADR，并提供迁移和兼容策略。
